# 验证记录

本次源码发布使用全新依赖目录，重新构建原生适配器、Schema、tokenizer 和前端，运行 312 项回归。

README 图片来自本版本真实组件的浏览器测试，全部使用演示对话、配置和费用。输入框、费用、设置各有中英文截图；另有 20 项响应式检查。它们证明组件渲染与交互边界，不代表服务商实时缓存收益。

Windows 安装脚本通过语法、在线参数、离线参数、损坏包拒绝和非法版本拒绝检查。CI 还运行 Windows 默认启动器测试，使用替身 CLI，避免触碰真实 DSH 配置。

构建与测试入口都在仓库，CI 结果可在 Actions 中查看。测试不需要模型密钥，不调用收费模型。实际服务商缓存寿命、第三方余额接口与预测质量仍取决于你的后端和对话，不能由这些测试替代。
