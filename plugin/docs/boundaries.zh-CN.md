# 边界、失败与统计

[English](en/boundaries.md) · [README](../README.md)

| 情况 | 处理 |
| --- | --- |
| 助手错误、中断、取消或未正常结束 | 不自动预测 |
| 输入框已有文字、附件、IME、菜单或排队发送 | 不覆盖用户输入；不满足条件时隐藏建议 |
| 切换线程或迟到响应 | 校验线程与来源，旧响应不显示到新位置 |
| 连续 UI 观察、窗口切换 | 复用结果或在途作业，不重新购买同来源预测 |
| 用户发送下一轮 | 旧建议退出显示，等待新轮正常完成 |
| 外部插件修改历史 | 重新映射；保留前缀估计低于 50% 时暂停 |
| 主线程压缩或工具裁剪 | 使用新的有效快照，区分正常上下文变化与失效事件 |
| 上下文超限 | 按完整单元选择窗口；不能安全构造时跳过，不拆断工具配对 |
| 模型依据不足 | 接受 suggestion:false，关闭本次显示 |
| 超长、语言不一致、解释性答案等 | 本地拒绝；默认至多一次校验修复 |
| 开启截断且只超长 | 在阈值内截断，不为这一原因再发修复 |
| 网络失败 | 自动重试可关闭；默认最多 3 次。用量未结算时先停止 |
| 关闭自动重试 | 本次不显示，等用户主动重试 |
| 切换思考策略 | 保存后生效，不自动重算当前轮 |
| 未知第三方模型控制 | 要求声明能力，不收费试探，不猜余额端点 |
| 明确的额度不足 | 暂停被动预测，才启动额度恢复检查；不按秒轮询 |
| 余额 API 不支持 | 不编造余额；额度层允许用户主动重试 |
| 价格不明确 | 调用前阻止自动消费，要求配置价表 |
| 服务商未给最终 usage | 未结算状态保留，阻止重复自动调用 |
| 只缺缓存细项 | 保持未知，按已有总量计算上界或区间，不记成零 |
| 多币种 | 分别汇总，不暗中合并 |
| 工作区或线程黑名单 | 优先于默认启用和旧线程补生成 |
| 已保存结果隔了很久再打开 | 不按时间过期；仍需来源与接受资格校验 |

额度恢复只在明确的主请求或预测额度拒绝后启用。官方 DeepSeek 可使用其余额接口；成功调用或确认恢复后解除这次监测。手动重试不绕过黑名单、来源、价格等其他限制。

24 小时 / 最多 3 个是旧线程补生成窗口，活跃时间按用户发送判断；不是助手最后产出时间，也不是结果 TTL。新线程默认开关与该时间无关。

## 占比怎么看

Prediction /（主会话 + Prediction），分线程、币种和覆盖范围计算，包含预测重试与修复的全部物理尝试。历史缺价或用量缺失不补零；安装后完整覆盖与历史缺口分开。

账本是按服务商 usage 与保存价表计算的估算，不是服务商账单。峰谷规则、时区和价格生效区间由价表决定。服务商隐藏缓存细项时，无法宣称缓存命中为 0% 或 100%。

## 能验证什么

回归使用合成上下文和模拟网络，检查真实序列化、生命周期、限制门与账本计算；不测服务商实时余额、缓存存续或建议质量。截图中的演示费用不作为省钱实测。

仓库 CI 记录当前构建和测试结果。Windows 安装脚本测试验证参数、校验和与 DryRun，不会替用户执行 DSH 安装。原生桌面截图另注明捕获版本。
