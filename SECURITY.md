# 安全报告

请使用本仓库的 Private vulnerability reporting 提交安全问题。普通缺陷可提 issue。

不要在公开 issue、日志或截图中附带 API Key、认证头、完整聊天、contexts 目录或 SQLite 账本。提供复现步骤、插件版本、DSH 版本与脱敏错误码即可。

Use private vulnerability reporting for security issues. Never attach credentials, full chats, context snapshots or billing databases to public issues.
